# Changelog

All notable changes to RPS Arena are documented here.

## [Unreleased]

### Added

- Kotlin and Compose Multiplatform architecture for shared Android/Desktop UI and game logic.
- Classic and Rock–Paper–Scissors–Lizard–Spock rule sets.
- CPU and same-device two-player play.
- Easy, Normal, and Expert transparent CPU strategies with deterministic seeds.
- Best-of-3, Best-of-5, Tournament, Endless, and Streak modes.
- Local statistics, achievements, recent history, backup/restore, themes, reduced motion, and round timers.
- Android and desktop persistence adapters.
- Responsive navigation and About/support/funding UI.
- Shared unit tests, Android lint/build CI, Dependabot, and CodeQL.

### Security

- No account, analytics, ads, cloud dependency, or Android network permission.
- Local-only preferences and explicit destructive reset confirmation.

## [1.0.0] - 2026-08-19

Initial production-oriented project baseline prepared for release-candidate verification.
