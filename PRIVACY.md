# Privacy

RPS Arena is designed to work offline without an account.

## Data stored locally

The app stores only the data needed for local functionality:

- appearance and accessibility settings;
- selected game rules, CPU difficulty, timer, and deterministic seed;
- aggregate win/loss/draw and streak statistics;
- up to 30 recent round summaries.

Android stores this information in private application preferences. Desktop builds use the operating system's Java Preferences backend.

## Data not collected by the project

The application code does not include analytics, advertising, tracking, remote account, telemetry, payment, or cloud-sync SDKs. It does not require a network permission on Android.

Opening GitHub, email, or Buy Me a Coffee from the About screen hands the destination to the operating system. Those external services then apply their own privacy policies.

## Backup and deletion

Settings provides a plain-text local backup/export and import feature. A destructive reset requires confirmation and removes RPS Arena's locally stored settings, stats, and history.

Do not place sensitive information into the backup text field; RPS Arena is a game, not a secret-storage system.
