## Before requesting help

1. Read `docs/setup.md` and `docs/troubleshooting.md`.
2. Reproduce with the latest release or `main` when practical.
3. Include platform, app version, and exact steps.
4. Redact private file paths, personal data, credentials, tokens, and signing material.

Security vulnerabilities should be reported privately according to `SECURITY.md`, not as public issues.
