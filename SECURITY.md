# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Report them privately by email to `sanskarin@outlook.in` with the repository name, affected version, impact, and a minimal safe reproduction description.

RPS Arena intentionally has no default network permission, account system, analytics, or ad SDK. Security reviews should preserve that minimal attack surface.
