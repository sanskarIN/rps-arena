# RPS Arena v0.1.3 — Reliability & Cross-Platform Quality

## Release summary

`v0.1.3` is a focused public patch release following `v0.1.2`. The candidate changes strengthen regression coverage around local backup validation and deterministic CPU behavior while preserving the existing offline-first product boundaries.

## What's changed

### Backup and data-safety regression coverage

- Added coverage for negative statistics values in imported backups.
- Added coverage for inconsistent round totals and impossible streak values.
- Added coverage for history records with missing payloads.
- Continued enforcing rejection of malformed data before it can be treated as a successful backup decode.
- Preserved the existing `RPSARENA_BACKUP|1` compatibility contract.

### Deterministic gameplay regression coverage

- Expanded seeded CPU determinism checks across every supported difficulty and game variant.
- Added extended-variant gesture validation in addition to existing classic-variant coverage.
- Kept deterministic behavior platform-independent at the shared test level.

## Compatibility and boundaries

- No network multiplayer service is introduced.
- No cloud account or synchronization requirement is introduced.
- No analytics or advertising SDK is introduced.
- No production signing credentials belong in the repository.
- No large architecture replacement is part of this patch.
