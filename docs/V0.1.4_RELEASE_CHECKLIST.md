# RPS Arena v0.1.4 Release Checklist

Use this checklist against the final release candidate and then again against the exact `main` commit that will receive the `v0.1.4` tag.

## Repository checks

- [ ] `python3 scripts/check_format.py`
- [ ] `python3 scripts/check_docs_links.py`
- [ ] `python3 scripts/check_docs_coverage.py`
- [ ] `python3 scripts/check_for_secrets.py`
- [ ] `python3 scripts/check_android_privacy.py`
- [ ] `python3 scripts/check_version.py`
- [ ] `python3 scripts/verify_localizations.py`

## Kotlin / Compose verification

- [ ] `gradle :shared:allTests --stacktrace`
- [ ] `gradle :shared:desktopTest --stacktrace`
- [ ] `gradle :shared:assembleAndroidDeviceTest --stacktrace`
- [ ] `gradle :androidApp:lintDebug --stacktrace`
- [ ] `gradle :androidApp:assembleDebug --stacktrace`
- [ ] `gradle :desktopApp:classes --stacktrace`
- [ ] `gradle :webApp:composeCompatibilityBrowserDistribution --stacktrace`

## Apple verification

- [ ] `gradle :shared:linkDebugFrameworkIosSimulatorArm64 --stacktrace`
- [ ] iOS/iPadOS Xcode application build succeeds on the configured Apple-silicon simulator target.
- [ ] Any host-specific skipped target is documented rather than treated as a product failure.

## Rust verification

- [ ] `cargo test --manifest-path rust-engine/Cargo.toml --all-targets`

## Release review

- [ ] All intended v0.1.4 commits are meaningful and reviewable.
- [ ] No unrelated generated files or credentials are included.
- [ ] Backup schema compatibility is explicitly checked.
- [ ] Release notes match the actual diff.
- [ ] Final CI and security checks are green.
- [ ] Release tag `v0.1.4` targets the final verified `main` commit.
- [ ] Only verified artifacts are attached, with SHA-256 checksums where applicable.
- [ ] GitHub release is marked stable/latest only after the final verification gate.
