# RPS Arena v0.1.3 Release Checklist

Use this checklist on the exact candidate revision. A checkbox is evidence-driven: do not mark it complete from documentation alone.

## Release identity

- [ ] Previous public release is `v0.1.2`.
- [ ] Candidate branch is based on the intended `main` revision.
- [ ] Final release commit SHA is recorded before tagging.
- [ ] Tag is exactly `v0.1.3`.
- [ ] Tag points to the validated release commit.

## Source and documentation gates

- [ ] `python3 scripts/check_format.py`
- [ ] `python3 scripts/check_docs_links.py`
- [ ] `python3 scripts/check_docs_coverage.py`
- [ ] `python3 scripts/check_for_secrets.py`
- [ ] `python3 scripts/check_android_privacy.py`
- [ ] `python3 scripts/check_version.py`
- [ ] `python3 scripts/verify_localizations.py`

## Shared/gameplay validation

- [ ] `gradle :shared:allTests --stacktrace`
- [ ] Deterministic CPU behavior is covered by regression tests.
- [ ] Ruleset and match-mode transitions are covered where changed.
- [ ] Invalid/edge-case configuration behavior is covered where changed.

## Platform validation

- [ ] `gradle :shared:desktopTest --stacktrace`
- [ ] `gradle :shared:assembleAndroidDeviceTest --stacktrace`
- [ ] `gradle :androidApp:lintDebug --stacktrace`
- [ ] `gradle :androidApp:assembleDebug --stacktrace`
- [ ] `gradle :desktopApp:classes --stacktrace`
- [ ] `gradle :webApp:composeCompatibilityBrowserDistribution --stacktrace`
- [ ] iOS simulator/framework/host validation passes on supported Apple targets.
- [ ] `cargo test --manifest-path rust-engine/Cargo.toml --all-targets`

## Security and privacy

- [ ] Security workflow is green for the exact release revision.
- [ ] CodeQL is green for the exact release revision.
- [ ] No signing keys, store credentials, or private certificates are committed.
- [ ] Offline-first behavior and Android privacy invariants remain intact.

## Release artifacts

- [ ] Every uploaded artifact was generated from the exact tagged revision.
- [ ] Artifact filenames identify platform and version clearly.
- [ ] SHA-256 checksums are generated where packaging supports them.
- [ ] Checksums were verified against the uploaded/downloaded files.
- [ ] GitHub-generated source archives are available for the tag.

## Release notes

- [ ] Notes summarize only changes actually present since `v0.1.2`.
- [ ] No planned feature is described as shipped.
- [ ] No historical `v2.5.x` behavior is presented as newly introduced by `v0.1.3`.
- [ ] Known platform limitations are documented.
- [ ] Support/contribution/license information remains accurate.

## Publication

Recommended release metadata:

- **Tag:** `v0.1.3`
- **Target:** `main`
- **Title:** `RPS Arena v0.1.3 — Reliability & Cross-Platform Quality`
- **Pre-release:** disabled only when all release gates are genuinely green.
- **Latest release:** enabled if this is the newest public release.
- **Discussion:** optional.
- **Assets:** upload only verified artifacts; otherwise leave assets empty and use GitHub's generated source archives.

## Post-release smoke checks

- [ ] Release page resolves and shows `v0.1.3`.
- [ ] Tag resolves to the exact validated commit.
- [ ] Release notes match the final diff.
- [ ] Downloaded assets pass checksum verification.
- [ ] `main` remains green after publication.
- [ ] Release tracking issue is updated with evidence and closed only after all applicable gates are complete.
