# Code of Conduct

RPS Arena welcomes respectful participation from people of different backgrounds, experience levels, and perspectives.

## Expected behavior

Contributors and community members should:

- discuss ideas, code, and technical decisions respectfully;
- give specific, constructive feedback instead of personal attacks;
- assume good intent while still addressing concrete problems directly;
- respect privacy and avoid posting another person's personal or sensitive information;
- keep issue and review discussions relevant to the project;
- accept reasonable maintainer decisions about scope, safety, architecture, and release quality;
- help make documentation and technical discussion approachable to new contributors;
- report security-sensitive information through the process in `SECURITY.md` instead of disclosing it publicly.

## Unacceptable behavior

The project does not accept:

- harassment, threats, intimidation, or discriminatory abuse;
- sexualized comments or unwanted personal attention;
- deliberate humiliation or targeted hostility;
- doxxing or publishing private information without permission;
- impersonation, spam, or deceptive participation;
- knowingly posting credentials, private keys, personal user data, or undisclosed vulnerability details;
- repeated disruption after a maintainer has asked for a discussion to return to the technical issue.

## Technical disagreement

Strong disagreement about code is allowed. Keep it evidence-based:

- identify the behavior or design concern;
- provide a reproduction, test, benchmark, source, or concrete tradeoff when possible;
- separate criticism of an implementation from criticism of a person;
- use pull-request review and issues for decisions that benefit from a written record.

## Enforcement

Maintainers may edit, hide, lock, or remove project interactions that violate these expectations and may restrict participation when necessary to protect contributors or the project.

For conduct concerns that should not be handled publicly, contact `supportramsandesh@gmail.com`. Do not include unrelated private data in a report.

This project expects the same standards in repository issues, pull requests, discussions, release comments, and other official RPS Arena collaboration spaces.
